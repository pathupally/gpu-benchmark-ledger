# Data and provenance notice

This public package contains normalized research observations and metadata, not
raw Silicon Data or Ornn responses, authenticated portal captures, copied web
pages, or subscription-gated material.

Each normalized observation retains an upstream URI, retrieval date, record
locator, methodology version, and provenance fingerprint. A fingerprint names
the private source artifact used during normalization. Since that artifact is
not redistributed, the fingerprint is not an independently verifiable integrity
check for users of this repository.

Names, trademarks, source data, and database rights remain with their respective
publishers. The MIT license applies to original software in this repository, not
to third-party data. Users are responsible for complying with upstream terms
when retrieving or using source material.
